## 开始使用 TokenPro

只需三个步骤，即可完成 API 接入。

<div class="steps" />

### 1. 注册账户

访问 TokenPro 平台，注册并登录你的账户。

### 2. 创建 API Key

进入 API 密钥管理页面，创建属于自己的 API Key。

### 3. 调用 API

按照接口文档配置请求地址、认证信息和模型参数，即可开始调用。

::: tip 提示
请妥善保管 API Key，不要将密钥直接暴露在公开代码仓库或浏览器前端。
:::
