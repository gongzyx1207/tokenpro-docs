# 获取 API Key

API Key 是调用 TokenPro AI API 服务的身份凭证。开发者需要先登录 TokenPro 平台并创建 API Key，才能通过接口调用已授权的模型。

## 一、登录 TokenPro

访问 TokenPro 平台首页，使用注册账户登录。

## 二、进入 API 密钥管理

登录后，在用户中心找到 **令牌管理 / API 密钥管理** 页面。

在该页面，你可以查看已有 API Key 的状态、额度、使用情况等信息。

## 三、创建 API Key

1. 点击创建新的令牌或 API Key。
2. 设置令牌名称，建议使用便于识别的名称，例如 `MyApp-Production`。
3. 根据实际需要设置额度或有效期（如果平台提供相关选项）。
4. 确认创建。

创建成功后，平台会生成一串 API Key。

## 四、保存 API Key

请在创建成功后及时复制并妥善保存 API Key。

::: warning 重要安全提醒
- API Key 相当于账户访问凭证，请勿泄露给他人。
- 不要将 API Key 提交到公开 GitHub 仓库。
- 不要在网页前端代码中直接使用 API Key。
- 建议将 API Key 保存在服务器环境变量或安全的密钥管理系统中。
:::

## 五、配置 API Key

调用 TokenPro API 时，在 HTTP 请求头中添加：

```http
Authorization: Bearer YOUR_API_KEY
```

将 `YOUR_API_KEY` 替换为实际创建的密钥。

## 六、API Key 使用建议

- 为不同项目创建独立的 API Key，便于管理和追踪。
- 根据项目需要设置合理的额度限制。
- 定期检查 API 调用记录和消费情况。
- 如果怀疑密钥泄露，应及时在控制台禁用或删除对应密钥，并重新创建。

## 七、常见问题

### 1. API Key 创建后可以再次查看吗？

具体取决于平台当前的密钥展示机制。建议创建成功后立即复制并安全保存。

### 2. 一个账户可以创建多个 API Key 吗？

请以 TokenPro 控制台实际允许的创建数量和规则为准。

### 3. API Key 是否可以分享给团队成员？

不建议多人共用同一个密钥。建议按照项目或应用分别创建和管理 API Key。
